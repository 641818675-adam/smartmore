## 一、设计原则（VISION.OS）

1. **暗场是常态**：工业相机在暗场中工作。单暗场主题，`color-scheme: dark`，亮色分支已删。
2. **色彩语义化，光即状态**：解码青只属于"动作/选中/链接"（解码成功），激光红只属于危险，琥珀只属于待上市。**没有装饰性发光**——每种光都对应一个真实动作，这是这套语言的灵魂，改版不得退化成装饰光。
3. **层级靠三层表达**：底色 → 表面（发丝线边框 + 顶缘受光边 + `--e-1` 浅阴影）→ 浮层（`--e-3` 深阴影 + 模糊背板）。禁止用重投影堆砌层级。
4. **数字防误读**：料号/价格/数量一律等宽字体 + `tabular-nums`。
5. **动效有目的**：只表达空间关系（入场/弹层位移/景深推拉）与状态确认（按压/选中/合焦）。120ms 反馈 / 200ms 过渡 / 300ms 位移 / 460ms 签名档，`prefers-reduced-motion` 全站尊重。
6. **可及性底线**：触点 ≥ 44px（次级 ≥ 28px 且热区补偿）、正文对比度 ≥ 4.5:1、占位 ≥ 3:1、`focus-visible` 全组件、允许页面缩放。

## 二、设计令牌（`tokens.css`，唯一取值来源）

### 2.1 色彩（全部为暗场取值，禁止新增令牌外颜色）

| 令牌 | 值 | 语义 |
|------|-----|------|
| `--bg` | `#0b0d12` | 页面底色（叠蓝图网格纹理） |
| `--surface` / `-2` / `-3` / `-hover` | `#151922` / 白6% / 白10% / 白4.5% | 卡片表面 / 输入次级面 / 按压态 / 悬停态 |
| `--border` | 白 9% | 发丝线 |
| `--text` / `-2` / `-3` / `-4` | `#eceef2` / `#9aa1ae` / `#8a92a0` / `#5e6672` | 主文 / 次文 / 辅助（≥AA） / 占位（≥3:1） |
| `--accent`（解码青） | `#2af5cf`（+`-strong/-hi/-soft/-softer/-text`） | **仅动作/选中/链接**；高能态全站只有 `.btn.primary` 与 `.chip.on` 两处 |
| `--st-active/-pending/-phasing/-retired` | `#3ee6a2` / `#ffb02e` / `#f2a94e` / `#969ca8`（各配 14%~18% tint 底） | 物料生命周期：可售/待上市/准备下架/退市 |
| `--danger` | `#ff5c4d` | 破坏性动作（激光红） |
| `--star` | `#f5b23c` | 收藏星标 |
| `--trace` / `--grid-line` / `--edge-hi` | 青 5.5% / 青 4.5% / 白 6% | 签名纹理：扫描线 / 蓝图网格 / 受光边 |

硬规则：`--accent` 与状态色不得互相挪用；新组件禁止引入令牌外颜色（渐变明暗与 color-mix 透明度除外）。

### 2.2 字体（10 级字阶栅栏）

核心 8 级：`--fs-11..17`（11/12/13/14/15/16/17）+ `--fs-22`（详情主编号）。（`--fs-21` 零使用点，2026-08-31 退役。）
展示层 2 级：`--fs-24`（顶栏大标题）、`--fs-28`（预留：空态/启动屏大字）。

硬规则：CSS 与 JS 渲染层**禁止裸字号**，一律 `var(--fs-*)`；`tools/test_design.js` 断言所用字阶 ⊆ 10 级、核心 8 级全在用、展示层只出现在 topbar/splash/empty 三类选择器。
字体栈：`system-ui → PingFang SC → HarmonyOS Sans SC → Microsoft YaHei`；等宽 `--mono`（料号/价格专用 + tnum）。

### 2.3 间距 / 圆角 / 阴影 / 动效

- 4pt 网格：`--sp-1..8`（4/8/12/16/20/24/32/40）。
- 圆角：`--r-xs 7 / -s 10 / -m 14 / -l 18 / -xl 24 / -full`。
- 阴影三档：`--e-1`（表面）/ `--e-2`（英雄卡）/ `--e-3`（浮层），`--e-hover` 同族更开。
- 动效：`--dur-1..4`（120/200/300/460ms）+ `--ease-out/-emph/-spring`（spring 只允许作用 transform）。

### 2.4 布局与断点

| 断点 | 布局 |
|------|------|
| < 600px | 单栏，详情为全屏 sheet（`body.sheet-open` 景深后退） |
| 600–839px | 双栏：左栏 `clamp(300px, 40%, 400px)` + 右详情通顶 |
| ≥ 840px | 双栏宽屏：左栏 `clamp(340px, 36%, 440px)` |
| pointer: fine | 桌面分支：顶栏兜底 `--topbar-pad-top` 降为 8px、显示细滚动条、Toast 定宽（见 §6） |

底部悬浮玻璃胶囊导航**全断点统一**（宽屏仅居中定宽）——这是拍板的设计语言，不是缺陷。

## 三、签名层（母题，只加不出新种类）

- **取景框 `.vf`**：四角框标只出现在"值得对焦"的内容上（料号速览/详情英雄卡/类别入口卡/空态图形/启动 Logo）；详情层出现时播 `vfInTL/vfInBR` 合焦动画。
- **CRT 扫描线**（body::before）与**详情英雄卡 trace 纹理**：静态零成本底噪。
- **蓝图网格画布**（--grid-line）：body 与 sheet 同一张绘图板。
- **顶栏下缘青激光发丝线**（topbar::after）：静置不闪。
- **对焦刻度线 / navPop**：底部导航选中态的弹性起跳。

## 四、组件状态完备性要求

每个可交互元件必须齐备：默认 / hover（仅 `@media (hover:hover)`，防触屏悬停残留）/ active（scale 按压）/ focus-visible / 选中（.on/.sel）/ 禁用 / 加载（spinner）。空态必须语境化（`UI.empty` 图形 + hint + 出口按钮）。

## 五、工程守门（改样式必须跑）

```
node tools/test_core.js   # 23 项：数据与套包逻辑
node tools/test_ui.js     # 155 项：渲染与交互契约
node tools/test_design.js # 对比度实算 / 10 级字阶栅栏 / 零内联 style / 死令牌 / 展示层字阶用途
```

对比度算法 = WCAG 2.1 相对亮度；徽章按 tint 合成到表面复算 ≥4.5。栅栏断言任何 `var(--fs-*)` 必须出自 10 级令牌——**换主题色不需要改测试，换字阶必须改这里**。

## 六、桌面大屏适配层（2026-08-31 增补）

1. **阅读度量**：详情栏内容 `max-width: var(--measure)`（820px）；单栏画布模式内容 `var(--measure-wide)`（1200px）定宽居中。
2. **单栏画布模式**：竞品/客户/收藏三个"非查料"页签在 ≥600px 由 `body[data-tab]` 驱动收起空详情栏、列表栏展宽为画布（窄屏行为不变）。
3. **顶栏兜底**：`--topbar-pad-top` 真机 34px / 桌面（pointer:fine）8px。
4. **滚动条**：`pointer: fine` 显示 8px 细滚动条（surface-3 滑块）；触屏维持隐藏。
5. **Toast**：≥600px 定宽 420px。

改动历史与证据链见 `docs/UI大屏审计与升级计划-20260831.md`。
