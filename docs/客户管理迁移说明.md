## 二、数据一致性与迁移路径

- **桌面版数据源**：`%APPDATA%/PartFinder/.../data.db` 的 `customers` 表（桌面机本地）。
- **移动端存储**：原生 SharedPreferences（`partfinder_prefs`）→ localStorage → 内存，三级降级
  （与本应用收藏/设置同一机制）。字段值与桌面版逐列同名。
- **迁移工具链（离线可用）**：
  1. 桌面机执行 `PartFinder_V9.7/scripts/export_customers.py` → 导出 `partfinder-customers` JSON（零依赖，自动尝试复制剪贴板，可 `--out` 存文件）；
  2. 通过任意离线通道（微信/邮件/USB）传到手机；
  3. 手机端「客户 → 从桌面版导入」粘贴 JSON → 按 `name+address` 去重合并，**保留原始 id 与创建时间**。
- 导入幂等：重复导入同一份 JSON，全部命中去重（added=0），可安全重放。
- 注意：移动端存量客户不会自动回传桌面版（桌面版无导入客户功能，属桌面版待办）。

## 三、平台差异与等效替代方案（安卓端限制说明）

| # | 平台限制 | 等效替代方案 |
|---|----------|--------------|
| 1 | WebView `file://` 页面无法使用 SQLite | 沿用本应用既有三级持久化（SharedPreferences 优先）。可靠性经收藏/设置两代验证；容量对客户量级（数百条内）无压力 |
| 2 | 移动端无报价单模块（桌面版「选中客户 → 报价页 → PDF」整链路不在移植范围） | 「选中客户 → 复制整包清单」自动在文本头部拼 `客户: X\n收货地址: Y`，与桌面版报价文本的 `客户: xxx` 行同格式；详情页常显「报价客户: X」胶囊（R2-02），未选客户时输出原清单 |
| 3 | 无 QMessageBox | 应用内底部确认弹层（`confirmModal`），默认动作=取消，与桌面版 QMessageBox 默认 No 一致；删除正用于报价的客户时明示连带后果（R3-01） |
| 4 | JS 读剪贴板在 `file://` 非安全上下文不可用 | 原生桥接新增 `paste()`（MainActivity），导入弹层自动预填剪贴板中的导出 JSON；Android 10+ 后台读剪贴板限制不影响本场景（应用前台） |
| 5 | 桌面版表单回车提交无对应键盘事件 | 输入框接入 Enter 提交 + `enterkeyhint="done"`（R3-03），输入法「完成」键即保存 |
