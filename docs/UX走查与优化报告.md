## 三、已实施的优化说明

### 3.1 折叠屏/窄屏 flex 高度塌陷（P0）

**问题**：`.pane` 使用 `height: 100%`，在窄屏（如 Fold3 外屏 832×2268）下被 flex 容器压缩，列表区渲染为 0 高度黑屏。

**修改**：`web/css/app.css`

```css
.main {
  flex: 1; min-height: 0;
  display: flex;
  align-items: stretch;   /* 新增 */
  overflow: hidden;
}
.pane {
  min-width: 0; min-height: 0;
  flex: 1 1 auto;         /* 替代 height: 100% */
  overflow-y: auto;
}
.pane-list { flex: 1; min-height: 0; }
```

**回归验证**：r05_cover.png / r07_inner.png 显示列表区与详情区均正常渲染。

### 3.2 套包规则未覆盖告警（P0）

**问题**：VN4000 等 174 条物料无配置线缆/配件规则，详情页只展示主机，销售误以为这就是完整清单，漏录 CRM。

**修改**：`web/js/app.js` / `web/js/contract.js`

- `resolve()` 新增 `hasCable` 标志，用于判断是否有线缆规则命中。
- 当 `!hasCable` 时，详情页顶部渲染 `.contract-warning` 琥珀色提示。

```js
function kitWarningHTML(m, set) {
  if (set.hasCable) return '';
  // "套包规则未覆盖：该系列 暂无线缆配置，下方清单缺少线缆料号。请按选型手册人工补齐后再录入 CRM。"
}
```

**回归验证**：离线测试 `VN4000-101-021` 详情 HTML 包含 `contract-warning` 与"人工补齐"。

### 3.3 复制整包清单不再混入线缆长度变体（P1）

**问题**：原 `optional` 把同一系列所有适用项都放进去，导致 VS1000P-111-022 的"整包清单"含 21 行（其中 16 行是不同长度的线缆变体），粘进 CRM 会多录。

**修改**：`web/js/contract.js`

- 将 `applicableItems` 按角色拆分为 `optional`（真配件：电源、支架等）与 `alternates`（已选角色的长度变体）。
- `toText()` 仍输出 `required + optional`，`alternates` 仅用于详情页备查。

**效果**：

- VS1000P-111-022 复制清单从 **21 行 → 5 行**。
- 详情页新增「同款其他长度 · 16」灰色区块，明确标注"不计入复制清单"。

### 3.4 型号输入归一化与空格并集提示（P1）

**问题**：用户从 Excel/PDF 复制型号常得到 `VS1000P - 111 - 022` 或 `VS1000P 111 022`，搜索引擎把空格当分词符，`VS1000P 111 022` 返回 85 条。

**修改**：`web/js/app.js`

```js
function normalizeQuery(q) {
  return String(q || '')
    .replace(/\s*-\s*/g, '-')  // 连字符两侧空格收拢
    .replace(/\s{2,}/g, ' ')   // 连续空格压缩
    .trim();
}
```

- 对 `VS1000P - 111 - 022` 归一化后精确命中 1 条。
- 若仍有空格导致结果 >12 条，显示提示「空格按多关键词并集匹配…」并给出「按去空格重查」按钮，`VS1000P111022` 精确命中 1 条。

### 3.5 空状态分因与可操作入口（P1）

**问题**：原来搜索无结果统一显示"没有匹配的物料 / 试试型号片段"，无法处理筛选过窄、关键词太短等真实成因。

**修改**：`web/js/app.js` 的 `searchEmptyCopy()`

- 有筛选条件时："当前条件下没有物料 / X + Y 过滤掉了全部结果"，按钮「清除全部筛选」。
- 关键词不存在时："没有找到「X」/ 试试更短的型号片段…"，按钮「清空关键词」。
- 关键词太短或含空格时给出对应引导。

### 3.6 无障碍改造（P2）

**修改**：

- 导航按钮加 `role="tab"`、`aria-selected`、`aria-label`。
- 收藏星、清空搜索、返回、卡片加 `aria-label` / `aria-pressed`。
- 卡片加 `role="button" tabindex="0"`，并支持 `Enter`/`Space` 键盘激活。
- CSS 加 `:focus-visible` 聚焦环，确保外接键盘/读屏用户可见焦点。

### 3.7 无关键词时总数文案诚实化（P2）

**修改**：`renderList()` 的 `result-meta`

- 原："共 90 条"
- 新："共 1213 条 · 列出前 90 条"

避免用户误以为库内只有 90 条物料。

### 3.8 测试与构建鲁棒性（P2）

**问题 1**：`tools/test_ui.js` 的 `uncaughtException` 处理器静默吞掉异常，导致测试假绿。

**修复**：改为打印堆栈，测试断言失败时退出码 1。

**问题 2**：`build.py` 使用 `shutil.rmtree` / `unlink`，在 WorkBuddy 沙箱中会被删除保护拦截。

**修复**：引入 `discard()` 辅助函数，用「重命名到系统临时目录」替代删除，构建稳定通过。
